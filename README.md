# Fukurou Developers Website

Fukurou Developersの公式ウェブサイトです。

## 概要

Fukurou Developersは、「Bringing joy to learning and embracing challenges!」を使命とする組織です。学習に喜びをもたらし、挑戦を受け入れる文化を育む革新的なプロジェクトを開発しています。

## 特徴

- 🌐 日本語・英語対応
- 📱 レスポンシブデザイン
- 🎨 モダンなUI/UX
- ⚡ 高速ローディング
- 🔧 保守性の高いコード構造

## 技術スタック

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- レスポンシブデザイン

## ファイル構成

```
fukurou-developers-website/
├── index.html      # メインHTMLファイル
├── styles.css      # CSSスタイル
├── script.js       # JavaScript機能
└── README.md       # プロジェクト説明
```

## 使用方法

1. リポジトリをクローン
2. ブラウザで`index.html`を開く
3. 言語切り替えボタンで日本語/英語を選択
